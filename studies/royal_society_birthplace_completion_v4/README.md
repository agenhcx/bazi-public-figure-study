地名保留原拼写；不同半球的同名地点或缺少必要地理依据时保留未知。不凭国籍、任职机构、教育地或亲属居住地推断。地理解析等级单独为 S3，不新增出生国家或精确出生点坐标。新取得的生日文字未用于改写原生日，日期差异另有审计记录。
