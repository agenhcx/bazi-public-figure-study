## 核验与下一步

NAS原ZIP和CSV哈希与冻结摘要精确一致；RS完整crosswalk在内存重建后哈希与冻结值一致；德、法、日及CAS逐表重算。CAS ZIP全部10,695清单项的SHA／字节／CRC及精确10,696成员已核验，只提取必要元数据，未执行包内代码。德国35个旧清单成员中30个原字节匹配，5个JSON/MD仅LF与历史CRLF不同，全部CSV原字节匹配；旧文件没有被修改。各国审计保留原文件哈希、公式及限制，统一汇总表不重写既有原生来源政策。

下一步应先确定统一出生／入院窗口与院体角色范围，映射并保留原生证据层，再处理跨院体及奖项重叠，并在计划比较的各分层中统计缺失。完成这些之后再审阅共同分析队列。本次没有新增采集、DOB或会籍接受、八字变量、显著性检验或统一cohort冻结；各子项目此前的冻结状态原样保留。
