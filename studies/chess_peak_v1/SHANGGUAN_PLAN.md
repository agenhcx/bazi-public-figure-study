# Shangguan and observed peak Elo: fixed exploratory description

The user requested this analysis before any further predictive-model training. Freeze this definition and code before inspecting the new associations. Earlier snapshot-Elo results and individual examples have already been seen; this is not a new blind preregistration or a causal study.

Use all original 2013 development players (1000) and all original 2023 NEW players (500), with their audited standard-rating maximum through December 2023. Analyze and report the two person-disjoint cohorts separately. Never select a definition, source, age restriction, person, or later model using these associations. No pooled-cohort estimate, predictive-model fitting, or confirmatory p-value is requested.

Two fixed definitions are reported in this order:

1. Primary: whether the month branch's main hidden stem is Shangguan (0/1).
2. Secondary: the number of Shangguan relations among year stem, year-branch main qi, month stem, month-branch main qi, and day-branch main qi (0–5). The day stem is the reference and its deterministic self-relation is excluded.

Shangguan means the candidate stem's phase is generated by the day stem's phase, with opposite yin/yang polarity. Phase order is wood, fire, earth, metal, water. Branch main qi is 子癸、丑己、寅甲、卯乙、辰戊、巳丙、午丁、未己、申庚、酉辛、戌戊、亥壬. No adjustable hidden-stem or position weights are used.

For each definition in each cohort, report every observed level's count, mean and median peak Elo; Pearson correlation (point-biserial for the primary binary definition) and its conventional 95% Fisher interval; and the unadjusted Elo difference per unit from an intercept-plus-feature OLS description, with a 95% HC3 heteroskedasticity-robust Student-t interval. For the secondary count also report Spearman rank correlation. No missing person is silently discarded. Missing required fields, nonfinite values or invalid symbols stop the analysis; constant features or rank-deficient designs produce explicit unavailable statistics.

As a fixed sensitivity description, report the feature's OLS Elo difference and 95% HC3 interval after adjustment for age and age squared, with everyone aged at the common 2024-01-01 boundary (days / 365.2425). Center age within the cohort before constructing its square. Also report the Pearson correlation of feature and rating residuals after removing that same age polynomial. This descriptive regression is not the paused predictive-model experiment. No age groups are excluded.

Intervals are descriptive, unadjusted for the multiple estimates, and do not establish causality or a universal BaZi rule. Selection into high-rated chess cohorts, calendar/birth-year structure, omitted factors and unfinished careers can affect these results. Age adjustment is a limited sensitivity check, not proof that these problems are resolved. A positive estimate whose interval includes zero remains uncertain. The two definitions are related and are not independent replications.
