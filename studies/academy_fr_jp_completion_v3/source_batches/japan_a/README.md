Baseline: PR113 commit a7297e662502ce821c9289dc7d5226b82208b92d. This is a bounded follow-up on 60 assigned science-member candidates, plus an existing-source bulk table matched against the same 482 stable IDs. No new people were added to the cohort and no analysis was run.

- `claims.json`: 8 institutional/organization-hosted records, covering 5 day statements (one held conflict) and 3 year-only statements. Esaki's Japan Prize body was read through the web retrieval tool; an additional raw HTTP request returned503, so its original-body hash is null. Kaya's nonprofit-founder history PDF was captured and its birthday box visually checked; a different death-day statement elsewhere in that box is preserved as source-quality context, not silently used to change a birthday.
- `secondary_claims.json`: 36 separately attributed claims for 34 people from complete edited dictionary articles hosted on Kotobank. Publishers and dictionary titles are explicit. They are not Wiki derivatives or first-party institutional DOBs. A primary institutional year-only source does not establish institutional support for the corresponding secondary day.
- `bulk_gsj_claims.json`: 8 distinct candidate IDs from the Genetics Society's historical presidents table, printed page28 / PDF index27. Two pre1873 dates remain unconverted; six are later day statements. Komai repeats the old seed. Kihara has an independently matching professor/date context. The table does not prove Academy subsection or final cohort eligibility.
- `bulk_gsj_inventory.json`: all 27 table positions, 25 unique names. Ten matching positions represent 9 candidate names because Kihara appears twice; 8 of the names have a birthday, while Furuhata's birthday is blank. Names outside the existing482 were not imported as new cohort members.

Every competing statement was read in an actual body. Hirayama's scientific-history PDF page image confirms printed3, so it is not repaired as an OCR omission. No source-count vote was used.
- `processed.csv`: all 60 assignments.48 were processed;33 have body day claims,3 are explicit source conflicts,2 are old-calendar holds,10 bounded searches produced no usable body birth claim, and12 were not processed this round.

Across the three claim files there are 52 claim rows and 44 unique people. Source-body support, conflict status, scientific qualification, birth-year window and final cohort acceptance remain separate. All final-cohort and BaZi flags are false/zero.

`source_capture_log.json` and `request_log.json` retain 43 actual source GET attempts,42 valid captured bodies, precise capture times/hashes,48 search queries and the relevant web-body/PDF visual references. One person (Kozai) had two bounded query routes. Search timestamps not supplied by the web tool were not invented. Long source excerpts have been removed from public logs.

The source PDFs, HTML, extracted full text and screenshots are retained only in `private/`. Do not publish that directory. The helper scripts read those private captures and use task-local paths; they are transcription utilities, not portable live production collectors. Publish only the files enumerated in MANIFEST.json, which excludes helpers and full copyrighted source material. Parent-level replay should consume the pinned claims and explicit holds.
