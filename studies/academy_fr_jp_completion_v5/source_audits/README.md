# Source review boundary

This directory holds independent QA metadata after collectors finish. It does not contain private copyrighted bodies or review images. No pending source is treated as approved because a request returned HTTP200 or a filename ends in PDF.

Each report records the collector/file/ID scope, actual body/date and same-person checks, original-capture hash checks, explicit calendar precision, corrected errors and remaining holds. `qa_report.schema.json` defines the shared envelope. A collector cannot independently approve their own delivery. Root owns the final source allowlist and publication decision.

For France, a strict positive requires an observed Academy-original ordinary-full-member event matching the accepted election day/year. Correspondent or foreign-associate events, eulogy dates and dated role bounds cannot provide that election date. All inherited conflicts, including Louis de Broglie's impossible source event, remain held.

For Japan, original calendar wording, literal January1 and source-supplied dual expressions stay separate. An unconverted alternate cannot erase an existing supported modern date. Edited dictionaries and financial reproductions stay separate from institution/university day support. A source failing actual body capture must not be assigned a fabricated original hash.

Code QA reports describe their exact recorded snapshot and review scope. The report for Japan's reducer, tier boundaries and Suzuki exception does not assert an unchanged source hash after later French outcome-accounting changes. Root's final review and the complete input/output replay establish the final integrated checks. Gravier's author/subject role correction is a withdrawn collector interpretation, not a newly fabricated disagreement between source documents.
