# France C v11 source batch

All 102 selected identities received one direct CTHS URL request, with serial access, a 15-second timeout and 0.4-second throttle. There were no person-search queries, retries, challenge workarounds or PDF probes. Every successful actual HTML is privately retained with SHA256.

The batch contains 59 strict membership-start approvals, 17 institutional-credit holds and 26 parked notices. Strict acceptance requires the same actual body to name Académie des sciences society506, type ordinary/free/nonresident membership, supply a literal start year or full-member interval, match the preserved identity/DOB, and explicitly credit the Académie des sciences or Institut de France as a notice writer/co-writer. The parent-institution branch records Institut authorship accurately. Individual authors, institutional bibliography, portrait credits and affiliation alone do not qualify.

Only metadata and short quotations are public. Full HTML remains private. Identity, DOB, existing conflicts, cohort status and analysis variables are unchanged. Correspondence, foreign membership, later section transitions and presidencies are kept separate. Independent review lives outside this immutable worker manifest.
