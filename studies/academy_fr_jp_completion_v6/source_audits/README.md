# v6 source and integration audits

Audit reports identify their exact scope and the source metadata or code snapshot reviewed. Source QA must distinguish original captured-byte hashes from extracted text hashes and state whether necessary PDF pages were visually verified. Browser-readable bodies with failed original capture require root approval for the exact member, URL, derived hash, failure status and independent verification reference.

Only public JSON/CSV/README metadata belongs in source batches. Private source bodies, review images and helper scripts are excluded. A report from a prior snapshot does not claim an identical hash for later edits. The integration invariants and deterministic replay verify cumulative ledgers, inherited holds, source tiers, unchanged selection/section scope and zero analysis outputs.
