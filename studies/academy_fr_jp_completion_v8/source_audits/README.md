# Evidence and integration audits

Source collectors exchange their original captures for independent review. Public QA records bind the final decision/claim files, original-body SHA256 values and relevant visual PDF review pages. Raw source files are private scratch evidence and are not redistributed.

The integration audit separately checks stable identities, inherited claim fields, provenance flags, calendar holds, the two v7 routing releases, membership/DOB dimensions, chronology conflicts and collection-only gates. A successful deterministic replay validates the committed evidence transformation; it does not establish national coverage or resolve an unsearched case.
